**Kora OS** — лёгкая система на Linux с интерфейсом в духе macOS / a lightweight Linux OS with a macOS-inspired interface.

- Запись на флешку: Rufus → режим **DD** / Write with Rufus in **DD** mode (or balenaEtcher / dd).
- Пароль живой системы / live password: `kora`.
- Проверка образа / verify: `sha256sum -c *.sha256`.
